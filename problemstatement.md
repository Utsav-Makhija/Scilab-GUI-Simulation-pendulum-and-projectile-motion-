## Problem Statement

In engineering and science education, understanding physical concepts often requires more than simply learning equations and theoretical definitions. Topics such as pendulum motion and projectile motion involve multiple variables, mathematical relationships, and changing physical states that can be difficult to visualize through traditional classroom methods alone. Students may be able to calculate values using formulas, but understanding how changing one parameter affects the overall behaviour of a system can be challenging. This creates a need for interactive simulation tools that can connect theoretical concepts with visual and numerical demonstrations.

The Engineering Simulation Studio addresses this problem by providing an interactive, computer-based environment for studying fundamental mechanics concepts through simulation. The objective is to develop a graphical application in Scilab that allows users to select a physics simulation, modify its parameters, observe the resulting motion, and analyze the corresponding numerical and graphical outputs. Rather than relying solely on static diagrams or manual calculations, the application provides a more interactive way of exploring how physical systems behave under different conditions.

One of the primary problems addressed by the project is the difficulty of visualizing dynamic physical systems. In a conventional approach, a pendulum may be represented by a diagram showing its length, mass, and angular displacement, while projectile motion may be represented by a static parabolic trajectory. Although these representations communicate the basic idea, they do not demonstrate how the system changes with time. The Engineering Simulation Studio aims to overcome this limitation by providing animated simulations in which the physical system can be observed as it moves. This allows users to develop a better intuitive understanding of concepts such as displacement, trajectory, time of flight, maximum height, and range.

The project focuses on two fundamental simulations: Pendulum and Projectile Motion. In the pendulum simulation, users can modify parameters such as length, mass, and angle and observe how the system responds. The purpose is to demonstrate the relationship between physical parameters and the resulting pendulum behaviour. The application complements the animation with calculated results and graphical representations, allowing users to study the system from both a visual and numerical perspective.

The second major component is the Projectile Motion simulation. Projectile motion is an important mechanics concept involving simultaneous horizontal and vertical motion. Students often have difficulty understanding how these two components combine to produce the characteristic parabolic trajectory. The application addresses this by allowing users to control the initial velocity, launch angle, and gravitational acceleration. The projectile is then animated from its starting point through its ascent, maximum height, and descent to its landing point. This provides a direct visual representation of the mathematical model.

Another important problem is the disconnect between mathematical calculations and physical interpretation. Performing calculations for time of flight, maximum height, or horizontal range gives numerical answers, but these values become more meaningful when they can be related directly to a visual simulation. Engineering Simulation Studio therefore combines numerical calculations with graphs and animations. For projectile motion, for example, the application provides graphs for height versus time, horizontal distance versus time, and the complete projectile trajectory. This allows users to compare calculated values with the graphical behaviour of the system.

The application also addresses the problem of repeatedly performing manual calculations when experimenting with different physical parameters. In a traditional setup, changing the initial velocity or launch angle would require recalculating all dependent quantities manually. In the proposed system, interactive sliders allow users to change parameters quickly. The corresponding results and visualizations can then be updated based on the selected values. This makes it easier to perform multiple experiments and observe relationships between variables without repeating lengthy calculations.

From an engineering education perspective, another challenge is providing students with practical exposure to computational modelling. Modern engineering frequently involves using software to model physical systems, analyze data, and visualize results. By implementing physics equations in Scilab and connecting them to an interactive GUI, this project demonstrates how theoretical mathematical models can be converted into functional computational simulations. It therefore serves not only as a physics visualization tool but also as an introduction to scientific computing, numerical methods, event-driven programming, and graphical data representation.

The problem also involves creating an interface that presents several types of information without making the application difficult to use. The Engineering Simulation Studio organizes the interface into distinct areas for simulation selection, parameter controls, simulation animation, results, and graphs. This organization is intended to make the interaction process straightforward: the user selects a simulation, adjusts its parameters, starts the simulation, and then examines the resulting motion, numerical values, and graphs.

Overall, the problem addressed by this project is the lack of an accessible and interactive way to connect physics theory, mathematical equations, numerical calculations, animation, and graphical visualization within a single application. Engineering Simulation Studio provides a focused solution by implementing two fundamental mechanics simulations in Scilab. Through interactive parameters and visual feedback, the system helps users understand not only what the equations calculate, but also how those calculations correspond to the actual behaviour of a physical system. This makes the project suitable for educational demonstrations, laboratory-style experimentation, and introductory engineering and computational physics applications.
